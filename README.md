# goit-algo2-hw-04

## Homework 4 – Prefix Trees (Trie)

### Task 1. Trie Extension

Implemented two additional methods for the Trie class:

- `count_words_with_suffix(pattern)` – counts the number of words ending with the given suffix.
- `has_prefix(prefix)` – checks whether there is at least one word with the given prefix.

Run:

```bash
python3 task1.py
```

---

### Task 2. Longest Common Prefix

Implemented the `LongestCommonWord` class inherited from `Trie`.

Method:

- `find_longest_common_word(strings)` – finds the longest common prefix for all strings in the list.

Run:

```bash
python3 task2.py
```
